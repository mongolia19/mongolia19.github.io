# 权重空间编程：大模型直接读写神经网络权重

> **作者**：卡兹克  
> **标签**：`AI` | `大模型` | `可解释性` | `论文解读`

---

MIT CSAIL 在 11 月 2 日挂出一篇论文，标题是 *Sparks of Weight-Space Programming*。它做的事可以用一句话讲完：把神经网络的权重原样喂给一个大模型，让这个大模型读懂它在算什么，然后再让它把权重改掉。整个过程不用梯度，不用优化器，也不跑反向传播。

作者是 Rikiya Takehi、Emily Teoh、Eric Zhang、Omar Khattab。用的模型是 GPT-6 Astra。论文里一共八个实验，从 1.7 万参数的小 MLP 一路做到 7.16 亿参数的字符级语言模型，最后改的是 Qwen3.5-0.8B。

## 为什么这件事以前做不了

训练神经网络本质是搜索。结构定下来，喂数据，让优化器把几十亿个数字往误差变小的方向推。推完模型能用了，但没人知道这些数字各自在干什么。可解释性研究做了这些年，能完整讲清的小回路也就那么几个。

行业里因此有个默认分工：代码可以手写，权重只能训。让大模型改 prompt、改训练脚本、改数据管线，都顺理成章。让它直接改权重，听起来不太现实，因为权重是十亿维的连续空间，没有任何人能写出来。

这篇论文的前提是：权重序列化成文本以后，前沿模型有能力把它当成一个程序来读。

## 一、它能不能读懂网络在做什么

**实验一：认游戏。**

四个网络，分别用 PPO 训练玩 Breakout、Pong、Pac-Man、Freeway。四个网络结构完全一样，都是 500→32→32→5 的 MLP，17253 个权重。只看形状和接口，没有可以作弊的地方。

Astra 拿到全部权重，回答一个问题：这个网络玩的是哪个游戏。没告诉它备选有哪些。

四个全对。Breakout 那个给了 99% 置信度，用了 846 个 token 的推理。解释里有具体坐标：通道 0 是 agent，权重集中在第 8 行、横跨可玩列，所以那是一块装在底部的挡板；通道 2 是奖励目标，结构集中在第 1 到 3 行，挡板上方一排带奖励的物体，也就是砖块。

**实验二：认图形。**

三个扩散模型分别生成圆、方、三角，各 23824 个权重。Astra 同样全对。偏差出在画图上：它把形状画成了轮廓线，而模型实际生成的是实心图形。

轮廓线和实心图的差别有解释。如果它在心里跑了一遍前向，画出来该是实心的。画成轮廓，说明它是按输出层里每个隐藏单元负责哪一段边缘来理解的。

**实验三：认训练语料。**

他们训练了三个字符级小语言模型，各 716 万参数，分别学 Python 代码、罗马字日语和英文。然后砍掉输入层和输出层，只留中间四层 transformer block。没有输入输出层，权重和字符的对应关系就断了，这个网络跑不起来。

Astra 可以写 Python 分析权重，但不能运行网络，连随机输入都不行，研究人员核对了每一次运行。

三次训练语料全答对，两次尝试都对。它还点名了每一个 induction head，也就是让模型重复前文的注意力头：Python 是 2.1、3.1、3.5，罗马字是 3.3，英文是 3.1。这些结果和跑模型测出来的一致，也没有误报。

找 induction head 的常规做法是跑模型看注意力图。这次是从数字里读出来的。

## 二、从读到写

**实验四：修一个卡住的小车。**

Kinetix 环境里的小车爬坡，车要先倒退一段攒够冲量才能越过红条。PPO 训了十亿步，收敛到局部最优：直接朝坡冲，然后卡住。256 局，一局没成。

Astra 拿到权重、场景描述和一局失败录像。要求它解释失败原因，并且只改这一点。一次回复，没给工具，它改了 171664 个权重里的 6073 个，占 3.5%。

改完，1024 局全过。

它给出的代码是这样的：

```
embed.W[:, 6:9] = 0
embed.b[6:9] = [0, 11, 0]
actor0.b[122:128] = [-200, -248, -304, -876, -760, -76]
actor_head.W[126, 0:3] = [-100, -100, 200]
actor_head.b[0] -= 200
```

整段 57 行，做法是在原网络里加一条旁路：读车的位置和速度，先往后倒攒冲量，等绿轮子右缘越过红条就关掉旁路，交回原来的策略走完剩下的路。

**实验五：从零写一个网络。**

不给数据、不给梯度、不给工具，也不许把网络放进环境里试。只给游戏规则和源码，让 Astra 一次写出 MinAtar 三个游戏的网络，权重从全零开始。

| 游戏 | PPO 1 亿步 | PPO 5 亿步 | Astra 一次写出 |
|---|---|---|---|
| Breakout | 15.8 | 25.3 | **517.4** |
| Seaquest | 5.6 | 88.9 | 53.1 |
| Asterix | 25.8 | 55.2 | 53.2 |

Breakout 这一项，Astra 的分数是训练五亿步的 PPO 的二十倍多。Seaquest 落后，Asterix 基本持平。

它写的权重里带注释，比如 `# Units 0..3: descending-right, descending-left...` 和 `# Subtract paddle position from each target`。它在写一条「预测球轨迹、减去挡板位置」的规则，再把规则编译成权重。

![MinAtar 三个游戏的得分对比](https://mongolia19.github.io/assets/weight-space-programming/fig1_minatar.png)

**实验六：围棋。**

围棋网络推到 148 万个权重，装不进上下文了。于是改给 Python 沙盒，加一个前向预算：每花一次前向，网络可以打 128 局练习赛。

0 次前向时，它写出的网络赢两个小 PPO 超过一半；给到 50 次前向，它赢过同等规模、训练两千万局的 PPO。

## 三、改一个真的语言模型

前面那些网络都小。第八个实验改的是 Qwen3.5-0.8B。

这模型有个公开的毛病，官方 model card 里就写了：thinking 时容易陷入循环，数学题做着做着开始重复，一路撞到 32768 token 上限。它的 MATH-500 只有 7.9%，93% 的答案是被截断的。

Astra 拿到权重、一个没有 GPU 的 Python kernel、一批练习题，以及最多 50 次前向。禁止梯度，禁止训练。

它先定位：循环有固定来源，是第 15 层和第 19 层 MLP 写出来的一个方向。然后把这个方向从两层各 64 个输出列里减掉。一共 131072 个权重，占整个模型的 0.016%。

结果：

| Qwen3.5-0.8B | MATH-500 | GSM8K | IFEval | 撞 32K 上限 |
|---|---|---|---|---|
| 原始 | 7.9% | 13.8% | 21.0% | 93.0% |
| 编辑后 | **48.1%** | **67.1%** | **62.3%** | **33.1%** |

![Qwen 编辑前后的三个基准](https://mongolia19.github.io/assets/weight-space-programming/fig2_qwen.png)

IFEval 涨了三倍。这个指标和数学无关，涨的原因是它不再把预算花在打转上，指令跟随自然就好了。

这类数字容易是运气，论文给了对照组：随机方向只涨 1.6 分，另外做了单层隔离和剂量响应。579 道原本被截断的题被救回来，5 道原本对的做错了。救回来的题，思考长度中位数 9172 token，没有靠强制截断。

![前向预算与收益](https://mongolia19.github.io/assets/weight-space-programming/fig3_budget.png)

10 次前向，MATH-500 到 12.3。25 次，14.1。50 次，48.1。

前 25 次它基本在原地试错，到 50 次附近才把强度调对。零反馈写权重和带反馈调权重是两种能力，这两组数字不能混着看。

## 四、作者自己说的局限

**实验七：谄媚和诚实。**

他们微调了两个 Gemma 3 270M，一个学诚实回答，一个学谄媚，用户说什么它就跟着说什么。只给权重，Astra 四次全错，能列出一堆差异，但对应不到行为上。放松一点，允许它自己写几段文本、只看两个模型的注意力图，三对全中。谄媚那个模型的 head 10.2，对用户建议答案的注意力是 85.7%，诚实那个是 0.75%。

有些东西能从权重直接读出来，有些得先做个实验。

**不循环的模型改不动。**

Gemma 3 270M 本身不循环，用同样的方法改数学，MATH-500 从 6.8 到 7.7，怎么改都没用。Astra 说它看到的只是普通的算术错误和无效的代数步骤，没有哪个组件可以关掉。

编辑能拆掉挡路的墙，造不出本来就没有的能力。这句话是论文对方法边界的说明。

**论文自己列出的边界。** 上下文装不下大模型，一百四十八万参数就得靠沙盒；harness 怎么设计直接决定上限；样本量小，好几个实验只跑了一次。作者在 What Comes Next 里把递归自我改进写成可能性，没当成结论。

## 五、两个还没有答案的问题

实验三里 Astra 找 induction head，用的是 Elhage 等人 2021 年提出的组合头分析方法，靠权重矩阵相乘来找。作者说没告诉过它。这可能是自己推出来的，也可能训练数据里就有，两种情况的意义差很远，论文没做区分。围棋那 336 行代码也是，写得像人写的评估函数。

在真的理解权重结构和见过足够多结构模式之间，这篇论文还没分清。

另一个问题是规模。多数实验的对象都很小，1.7 万、2.4 万、716 万、148 万参数，最后一个是 0.8B 的语言模型，改动量只占 0.016%。这套方法在 7B、70B 上是什么样，论文没有答案，因为权重根本塞不进上下文。

## 六、工程上意味着什么

三个方向在近期有实际用途。

**审计。** 拿到一个来路不明的开源模型，不用等测试集，直接读权重看有没有藏东西。这条路目前还很初步。

**定点修复。** 0.016% 的改动不用担心灾难性遗忘。SFT 一个模型动辄几万条数据、几张卡、几天，这里改的是十三万个数字，改完其他能力没掉。

**模型合并。** 现在合并基本靠权重平均，前提是结构一样。如果真能读懂权重，就能把 A 模型里的推理回路嫁接到结构完全不同的 B 模型上。这条还只是设想。

## 最后

行业里常说模型是黑盒。这话说了十年，大家也习惯了：训练靠玄学，调参靠手感，出问题就加数据重训。

这篇论文没有推翻这个说法。它在一个很小的尺度上把盒子打开了一条缝。缝里能看到的是，权重本身有结构，这些结构语言模型能读懂。

如果这条路走通，权重会从训练的产物变成可读、可写、可审的代码。好处是训练成本降下来。坏处也明显：能读就能改，能改就能藏。模型里塞了什么，以后可能要另一个模型来读。

作者说他们在做 benchmark 和 harness，想把这件事从黑魔法变成可复现的工程。在那之前，这篇论文是一个信号。
